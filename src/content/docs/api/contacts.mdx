Contacts record who you message and whether they agreed to it. A contact that replies STOP is marked `opted_out` and can't be messaged until they opt in again.

## Create a contact

<div class="endpoint"><span class="method post">POST</span>/v1/contacts</div>

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `phone` | string | Yes | E.164 phone number |
| `name` | string | No | Display name |
| `consent` | object | Yes | How and when the person agreed: `{ "source": "checkout", "at": "..." }` |
| `tags` | string[] | No | Labels for grouping, such as `vip` |

## Delete a contact

<div class="endpoint"><span class="method delete">DELETE</span>/v1/contacts/&#123;id&#125;</div>

Permanently removes the contact and their history. Use this when someone asks you to erase their data.
